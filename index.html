4. 추천시스템: 협업 필터링(CF) vs 콘텐츠 기반(CBF)

  • • 협업 필터링(CF): 집단 지성 활용. Memory-based(단순 산술연산, 설명력 높음, Sparse 취약) vs Model-based(기계학습, Sparse 처리 가능, 설명력 낮음).
  • • CF 4대 단점: ① Cold Start(신규 유저 데이터 부족), ② First Rater(신규 아이템 평점 부족), ③ Grey Sheep(일관성 없는 특이 취향), ④ Shilling Attack(악의적 평점 조작).
  • • 콘텐츠 기반 필터링(CBF): 아이템을 벡터로 표현. 타 유저 데이터 불필요, 신규 아이템 추천 가능. 단점은 적절한 feature 탐색 어려움 및 과도한 특수화(Over-specialization).
  • • 다양화(Diversification) 효과: 스크롤 화면에서 아이템별 클릭률 ↓, 스크롤 수 ↑, 인당 클릭 수 ↑ (장기 이탈률 감소).

5. NLP 핵심: 형태소·임베딩·Word2Vec 비교

  • • 「한나가 책을 보았다」: 자립(한나, 책) vs 의존(가, 을, 보, 았, 다) / 실질(한나, 책, 보) vs 형식(가, 을, 았, 다).
  • • 문장 임베딩 vs 단어 임베딩: 문장 임베딩(문맥 파악, 고품질, 고비용) vs 단어 임베딩(학습 간단, 동음이의어 구분 불가로 동일 벡터 표현 단점).
  • • 희소 표현 vs 분산(밀집) 표현: 희소(고차원, 대부분 0, 차원의 저주 - 원핫, BoW, TF-IDF) vs 분산(저차원 실수 벡터, 높은 일반화 - Word2Vec, GloVe, FastText).
  • • Word2Vec 비교: CBOW(주변➔중심 예측, 타깃 손실만 계산해 학습 속도 빠름) vs Skip-gram(중심➔주변 예측, 예측 맥락 많아 임베딩 품질 우수).
